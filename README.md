# 🎮 Sistema de Personagens RPG

Projeto desenvolvido em Java para praticar conceitos fundamentais de **Programação Orientada a Objetos (OOP)**.

## 📚 Conceitos praticados

* Encapsulamento
* Abstração
* Herança básica
* Construtores
* Getters
* Métodos
* `extends`
* `super`
* `@Override`

## ⚔️ Personagens

O projeto possui uma classe abstrata `Personagem` e duas classes que herdam dela:

* **Guerreiro** — possui força e uma habilidade própria.
* **Mago** — possui mana e uma habilidade que utiliza mana.

A classe `Personagem` possui características e comportamentos comuns, como:

* Nome
* Vida
* Nível
* Experiência
* Receber dano
* Recuperar vida
* Ganhar experiência
* Mostrar status

## 🛠️ Tecnologias

* Java
* Programação Orientada a Objetos

## 🎯 Objetivo

Projeto criado com o objetivo de colocar em prática os conceitos de OOP estudados e evoluir gradualmente no desenvolvimento com Java.

Pretendo continuar evoluindo o projeto e adicionar novos personagens e funcionalidades conforme avanço nos estudos de Java e OOP.
